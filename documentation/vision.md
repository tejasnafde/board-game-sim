# Vision

## Goals

- Let friends play turn-based board games online with low friction.
- Support multiple games via a common engine contract.
- Ensure fair play through authoritative server decisions and replayable history.

## Non-Goals (V1)

- Twitch real-time game support.
- Full marketplace/ecosystem for user-generated games.
- Native desktop-first release.

## Multiplayer Principles

- Browser-first join flow.
- Guest onboarding with optional account upgrade.
- Reconnect and resume are first-class capabilities.

## Fairness and Trust

- Server validates every move.
- Hidden information is redacted per player view.
- Deterministic execution + event logs enable audits and disputes.
